Get in touch

Found a bug, have a tool you wish Anvil had, or a question about how your data is handled? Anvil is a solo, open source project — every message is read, and every issue and pull request on GitHub is welcome.

Email dimitris.chatzi@proton.me

I usually reply within a few days. For bugs, your device and iOS version help a lot.

Bug reports

Found something broken? Create an issue on GitHub or email me directly. Every bug report helps make Anvil more reliable.

Feature ideas

Have a tool or feature that would make your workflow better? Open an issue on GitHub with your suggestion — they shape what gets built next.

Privacy & security

Questions about how tokens, checkpoints or notifications are handled? Ask away — the short answer is that it all stays on your device.

Open source

Anvil is open source on GitHub

The full source code is available for anyone to review, contribute to, or fork. If you want to contribute, report issues, or just see how it's built, head over to the repository.
