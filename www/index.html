What is Anvil?

Your side projects, watched from your pocket.

Anvil is an iOS toolbelt for developers. Point it at the websites and APIs you care about and it checks them on a schedule — status codes, response bodies and response times — then taps you on the shoulder only when something actually looks wrong.

Connect a GitHub token and you also get a dashboard of your profile and repositories. Skip it and everything else still works, because Anvil has no accounts, no backend and nothing to sign up for. The entire app is open source, so you can verify all of that yourself.

The rest is the stuff you reach for between tasks: a colour palette generator with live app previews, a regex builder, and a calculator that speaks bytes and bandwidth instead of just numbers.

Features

One app for the tools you keep hunting for

001

CHECKPOINTS

Add a website or API endpoint as a checkpoint and Anvil watches its status code, body and latency for you.

002

RESPONSE DIFFS

Capture a baseline response and see a unified diff the moment it changes — line by line, header by header.

003

IGNORE THE NOISE

Timestamps, build hashes, rotating cookies — mark the lines and headers that always change so only real regressions get flagged.

004

BACKGROUND CHECKS

Run checks every five minutes, once a day, or only when you ask. Anvil keeps checking in the background and stays quiet while everything is healthy.

005

SLOW RESPONSE ALERTS

Set how much extra latency is unacceptable and get told when an endpoint is technically up but crawling.

006

GITHUB DASHBOARD

Connect a personal access token to browse your profile, repositories and code stats from your phone. Entirely optional.

007

PALETTE GENERATOR

Build light and dark palettes side by side, preview them on real app layouts, and export the whole thing as JSON.

008

REGEX & CONVERSIONS

Assemble regular expressions from tokens and presets, and convert between bytes, bandwidth and the other units that never stick in your head.

Why Anvil

Built by a developer, for developers

Everything stays on device

No backend. No account. No analytics.

Your checkpoints are stored locally and your GitHub token lives in the iOS Keychain. Requests go straight from your phone to GitHub or to the URLs you configured — never through a server of mine.

Quiet by default

Alerts only when something is off.

Healthy checks stay silent. Notifications are reserved for unreachable endpoints, server errors, unexpected content changes and responses that have slowed past your threshold.

Free and open source

No subscriptions, no ads, nothing hidden.

Anvil is a solo project, built in SwiftUI out of the tools I kept wishing I had on my phone. The full source is on GitHub — read it, audit it, file an issue or send a pull request.
